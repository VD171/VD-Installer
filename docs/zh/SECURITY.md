# 安全策略

## 一句话威胁模型

VDInstaller 以 root 运行，并安装用户明确选择的 APK；为某次安装关闭 Play Protect 验证器会禁用恶意软件扫描，
所以这是“无摩擦安装”，而非“安全安装” - 只安装你信任的 APK。

## 它做什么与不做什么

- 默认情况下，它会将软件包验证器恢复到其之前的确切状态（在原本什么都没有的地方留下一个 `0`/`1` 本身
  就是一个痕迹，因此会再次将其删除）。
- 它绝不触碰你的 HMA-OSS 设置；隐藏应用是一项由你自己执行的建议。
- `packages.xml` 的安装来源编辑是 ABX 感知的，会在任何更改之前对活动文件进行逐字节精确备份，进行往返
  校验，并在任何失败时保持活动文件不被改动。
- 捆绑的二进制文件在构建时从其官方上游获取，并附带一个 `PROVENANCE.json`。
